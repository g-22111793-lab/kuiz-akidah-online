# Kuiz Akidah: Bahaya Riddah

Ini ialah laman kuiz interaktif yang boleh diakses secara online melalui GitHub Pages atau hosting statik lain.

## Ciri-ciri
- 20 soalan kuiz akidah
- Timer untuk setiap soalan
- Penjelasan jawapan selepas setiap soalan
- Skor akhir dan ulasan hasil
- Fungsi kongsian pautan
- Paparan guru dengan kata laluan
- Rekod markah dan kehadiran disimpan di localStorage

## Kata laluan guru
- guru123

## Cara aktifkan GitHub Pages
1. Pergi ke repository GitHub anda.
2. Klik Settings > Pages.
3. Pada Source, pilih Branch: main / root.
4. Klik Save.
5. Laman akan tersedia pada URL seperti:
   https://<username>.github.io/<repository-name>/
